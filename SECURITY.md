# Security Policy

## Supported Versions

Only the `main` branch is actively maintained.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in a public issue. Report them privately through GitHub's repository security contact mechanism or contact the repository owner through the GitHub profile.

Include:

- affected component or file
- reproduction steps
- expected and observed behavior
- relevant logs or proof of concept, if safe to provide

This project is an educational/research portfolio project and is not intended for production deployment without additional security hardening.
